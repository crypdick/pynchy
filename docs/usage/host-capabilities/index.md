# Host capabilities

Use optional host services when an agent needs a real desktop, a desktop image,
or spoken replies. These capabilities stay outside the agent container and run
through Pynchy's policy and approval boundaries.

| Capability | What it does |
|------------|--------------|
| [Computer use](computer-use.md) | Operate a host desktop through a selected provider plugin. |
| [Desktop screenshots](desktop-screenshots.md) | Capture and analyze the macOS desktop. |
| [Local speech synthesis](local-speech.md) | Run Pocket TTS for spoken channel replies. |

For Discord voice rooms and inbound audio transcription, see [Voice and
speech](../../channels/voice-and-speech.md).
